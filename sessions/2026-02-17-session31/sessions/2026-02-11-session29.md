# Coding Problem : 
https://leetcode.com/problems/median-of-two-sorted-arrays/description/
  - Optimised solution using Binary Search

# Solution :
```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int n1 = nums1.length, n2 = nums2.length, n = n1 + n2;
        if(n1 > n2) 
            return findMedianSortedArrays(nums2, nums1);
        int noOfElementsInLeftPart = (n + 1) / 2;
        int low = 0, high = n1, mid1 = -1, mid2 = -1;

        while(low <= high) {
            mid1 = (low + high) / 2;
            mid2 = noOfElementsInLeftPart - mid1;
            int la = Integer.MIN_VALUE, lb = Integer.MIN_VALUE;
            int ra = Integer.MAX_VALUE, rb = Integer.MAX_VALUE;
            if(mid1 > 0)
                la = nums1[mid1 - 1];
            if(mid2 > 0)
                lb = nums2[mid2 - 1];
            if(mid1 < n1)
                ra = nums1[mid1];
            if(mid2 < n2)
                rb = nums2[mid2];
            if(la <= rb && lb <= ra) {
                if(n % 2 == 0) {
                    int x = Math.max(la, lb) + Math.min(ra, rb);
                    return x / 2.0;
                } else {
                    return Math.max(la, lb);
                }
            } 
            if(la > rb) {
                high = mid1 - 1;
            } else if(lb > ra) {
                low = mid1 + 1;
            }
        }
        return -1;
    }
}
```
